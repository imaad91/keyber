# KEYBER

Coquille générique de simulation de décisions (Next.js 14).

## Démarrage

```bash
npm install
npm run dev
```

- Landing : [http://localhost:3000](http://localhost:3000)
- **Porte joueur** : `/jouer/live` → `/jouer/book/[id]` (Keyber OS)
- Ancien `/play` : redirige vers le catalogue Live (POC joueur retiré)

Contenu scénarios : fichiers Book sous `data/scenarios/`.
